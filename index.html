02

Coding Principles

Four rules that eliminate the most common LLM coding mistakes — over-engineering, scope creep, unnecessary refactors, and vague success criteria.

Think first

Don't assume. Ask.

State assumptions explicitly. Surface tradeoffs before writing a line. If something is unclear, name it and stop.

Simplicity

Minimum code.

No features beyond what was asked. No abstractions for single-use code. 50 lines beats 200.

Surgical

Touch only what you must.

Match existing style. Don't improve adjacent code. Every changed line traces directly to the request.

Goal-driven

Define success. Loop.

Transform tasks into verifiable goals. State a brief plan. Strong criteria let you loop without clarification.

before · over-engineered
// Abstract factory for user creation
class UserFactory {
  constructor(strategy, validator) {
    this.strategy = strategy;
    this.validator = validator;
  }
  create(data) {
    return this.strategy.execute(
      this.validator.validate(data)
    );
  }
}
