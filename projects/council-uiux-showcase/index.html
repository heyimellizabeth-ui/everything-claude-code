How it works

Three stages, anonymized and ranked

The council mirrors LLM-Council's deliberation: collect independent opinions, rank them blind, then synthesize. Here it decided this page's visual direction.

Collect opinions

Four voices — Architect, Skeptic, Pragmatist, Critic — answer the same question independently, with no shared transcript.

Rank blind

Responses are anonymized and ranked on merit, then aggregated by average position — no playing favorites.

Synthesize

A verdict reconciles the dissent. Here it changed the call: ship dark and a theme toggle, not just one.

Features

What the combined pipeline gives you

Four-voice council

Structured disagreement before a decision — anti-anchored subagents, surfaced dissent, one verdict.

Real design tokens

Palette, typography, landing structure, and chart choices come straight from ui-ux-pro-max's databases.

Score-gated build

A generate → evaluate → refine loop scores Design Quality, Originality, Craft, and Functionality.

Accessible by default

Strong contrast in both themes, visible focus, reduced-motion support, and SVG icons — checked at the quality gate.

Self-contained output

One static HTML file — Tailwind + Chart.js over CDN, no build step, opens straight in a browser.

Dual-reviewer gate

Two context-isolated reviewers must both pass before the work is considered shippable.
