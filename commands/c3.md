# C3 — Design Iteration Sprint

Use this chain for polishing existing UI: tightening animations, fixing responsive breakpoints,
improving visual hierarchy, or chasing a specific aesthetic. It skips heavy planning and goes straight
into iterative design-build cycles scored against a rubric.

## Chain

```
/model-route   Recommend the best model tier for this complexity and budget
/gan-design    Design loop: generate → score → refine (visual quality-gated)
/gan-build     Build loop: implement → evaluate → fix (score-gated)
/quality-gate  Lint, type check, format — confirm nothing broke
/code-review   Final review pass before committing
```

## When to Use

- Improving visual polish on an existing page or component
- Animation and transition refinement
- Responsive layout fixes across breakpoints
- Dark mode / theme work

## Tips

- `/gan-design` uses a higher originality weight (0.30) — it will push for creative leaps, not just safe fixes.
- Pass `--max-iterations 5` to `/gan-design` for faster sprints when the design direction is already known.
- `/gan-build` defaults to playwright evaluation; add `--eval-mode screenshot` for purely visual assessment.

## Usage

```
/c3 Polish the hero section — add a parallax scroll effect and tighten the mobile layout
```
